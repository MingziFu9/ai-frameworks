# 实验数据说明

每个数据文件一行，写清内容、规模、来源和使用章节。公开数据集写项目名和网址，并核对许可是否允许教学使用；编者自编的材料注明“教材编写，内容为虚构”。

| 文件 | 内容 | 规模 | 来源 | 使用章节 |
|---|---|---|---|---|
| `示例.csv` | 示例数据，写第 1 章时替换 | 3 条 | 教材编写，内容为虚构 | 第 1 章 |

**规模要求**：学生实验默认在普通笔记本电脑的 CPU 上运行，单个数据文件尽量不超过 20 MB，一次训练不超过 10 分钟。更大的数据只用于课堂演示（学校 A40 服务器）或云算力实验，放在网盘，这里只写下载地址和校验值，不提交到仓库。

**使用说明**：公开数据集仅用于教学和研究，请遵守原项目的许可说明，不得用于商业用途。虚构材料中出现的人名、机构、电话、证件号码均不对应真实的人和机构。
