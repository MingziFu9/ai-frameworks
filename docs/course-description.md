# 人工智能开发框架技术

**课程名称：** 人工智能开发框架技术

**授课对象：** 成人教育（开放教育）人工智能技术应用专业专科学生，多为在职学习者，线上自学为主

**学分学时：** 4 学分，72 学时（理论 60 学时，其中线上 46、线下 14；实验 12 学时，线上），第 4 学期开设，期末开卷考试

**先修要求：** 按 Python 零基础设计。学过“Python 程序设计”“机器学习”更好，但不作为前提：本书用到的 Python 知识在第 1–4 章的“Python 小课堂”和附录 A 里从头讲，用到的机器学习概念在使用处用一段速记和生活比喻讲清。

**两个版本：** 一本书、两套代码。概念讲解、动画、练习两版共用；代码和实验分“通用版”（Keras 3 为主，PyTorch 只读）和“国产版”（飞桨高层 API 为主，飞桨动态图只读，含 PaddleClas、PaddleOCR、PaddleNLP、PaddleSpeech 与 AI Studio），网页上用标签切换。

**对应证书：** 人才培养方案没有给本课挂证书。本课内容支撑三个高级证书里“深度学习框架”的部分：人工智能数据处理工程师（高级）“深度学习实战：TensorFlow 等框架的搭建、优化、部署”，Python 技术应用工程师（高级）“深度学习（TensorFlow / PyTorch）”，人工智能应用工程师（高级）“TensorFlow”。正文相关小节用“证书考点”提示框标出，不单独做对照页。

## 课程概述

开发框架是做人工智能应用的“工具箱”。识别一张花的照片、判断一条评论是好评还是差评、听懂一句语音指令，从准备数据、训练模型到做成别人能用的小工具，都是在 Keras、PyTorch、飞桨、昇思这类框架里完成的。

本课程面向几乎没有编程经验的学生，目标是“**能理解是底线，能用是加分**”：学完能说清一个 AI 模型从数据到应用的每一步在做什么，能读懂、运行并修改给定的代码，做出自己的小应用。课程采用“先做出东西、再讲原理”的顺序：第 2 章就用几行代码调用现成模型识别图片，之后每章打开一层，依次讲数据在框架里的样子、怎样用积木式写法搭网络、`fit` 训练时发生了什么、怎样看懂训练曲线和调参、怎样用迁移学习借用别人的模型，再做图像、文本、语音三类应用，最后把模型做成网页小工具发布出去，并了解国产 AI 生态、数据安全与相关法规。

全书 12 章、36 个实验，贯穿一个“花卉识别助手”项目。实验默认在魔搭、AI Studio 等云端 Notebook 上完成，打开网页就能运行；每个实验分“跑通”“改一改”“挑战”三档，前两档必做，给出完整代码，学生只需按提示修改。学校的 A40 服务器只用于课堂演示和编者实测。

## 主要内容

- 人工智能开发框架的作用与主流框架（Keras / TensorFlow、PyTorch、飞桨、昇思）；CPU 与 GPU、云端 Notebook
- 零基础够用的 Python（约 15 个知识点，边用边学）
- 调用现成的预训练模型做图像识别，读懂输出
- 数据在框架里的样子：图片、文字、声音怎样变成数字，数据集与数据增强
- 用积木式写法搭建神经网络，读懂网络结构表
- 训练模型：损失函数、优化器、轮次、批大小、学习率；`fit` 背后的五个步骤；保存、加载与预测
- 看懂训练曲线：欠拟合、过拟合，早停、Dropout、数据增强；TensorBoard / VisualDL
- 迁移学习与低代码训练
- 图像应用（目标检测、文字识别）、文本应用（情感分析、评论分类、调用大模型 API）、语音应用（语音识别与合成、语音指令分类）
- 把模型做成网页小工具并发布；模型压缩与其他部署方式（了解）
- 国产 AI 生态；数据安全、隐私保护与相关法规；综合项目

## 不涉及的内容

- 编写自定义网络类、自定义训练循环、自动求导等框架底层用法（只在第 5 章要求读懂一段训练循环）
- 神经网络原理和公式推导，归“机器学习”课程
- Transformer 与大模型原理，归“自然语言处理导论”；检测、分割的系统讲解归“计算机视觉及应用实战”；语音识别合成的系统讲解归“TTS/SST 与语音克隆”
- 接口服务、Docker、模型量化与生产部署的具体操作，只做了解
- 分布式训练、差分隐私、联邦学习等进阶内容

## 学习目标

完成本课程后，学生能够：

### 记忆（Remember）

- 说出人工智能开发框架的作用，列举至少两个通用框架和两个国产框架
- 复述模型、预训练模型、训练、推理、张量、数据集、轮次、批大小、学习率等基本术语
- 列出训练模型的五个步骤和训练前要做的三项设置

### 理解（Understand）

- 用自己的话解释图片、文字、声音是怎样变成数字交给模型的
- 读懂一段 15 行以内的框架代码，说出每一行在做什么
- 解释 `fit` 背后发生了什么，把一段训练循环代码和五个步骤对应起来
- 解释迁移学习为什么能在数据少的情况下得到好模型

### 应用（Apply）

- 在云端 Notebook 上运行给定代码，并按要求修改数据、参数，得到自己的结果
- 调用现成模型完成图像识别、目标检测、文字识别、情感分析、语音识别
- 按给定步骤训练一个图像分类、文本分类或语音指令识别模型，并用它预测新数据
- 用 Gradio 把训练好的模型做成网页小工具并发布

### 分析（Analyze）

- 根据训练曲线判断模型是学得不够还是死记硬背，选出合适的改进办法
- 对比不同设置的实验结果，找出影响效果的主要因素；查看认错的样本并分析原因
- 读懂常见报错信息，判断原因并改正

### 评价（Evaluate）

- 根据任务和条件，在通用框架和国产框架、现成模型和自己训练之间做出合理选择
- 判断一个数据集或模型能否安全、合规地使用

### 创造（Create）

- 从图像、文本、语音中任选一类，完成一个从数据到网页发布的小应用，并写出项目报告
