## 教学说明

**学习目标**

1. 能说出常见的个人信息类型和脱敏的做法（记忆）；
2. 能发现规则的漏洞，并说明为什么脱敏后还要人工检查（分析、评价）。

**画面与操作**

- 上方文本框是 5 条虚构的客服记录，可以任意修改；
- 勾选或取消规则，下方实时显示脱敏结果（橙色为遮住的部分），表格显示每条规则找到了几处。

**数据来源**：客服记录由编者编写，内容为虚构；身份证号使用不存在的地区代码 990101，手机号、银行卡号均为虚构。规则与实验 12-1 的 Python 代码相同。

**课堂用法建议**

1. 让学生把“13900001234”改写成“139 0000 1234”“一三九……”，看规则是否还能找到，讨论“规则总有漏网之鱼”；
2. 讨论哪些信息即使遮住了号码，组合起来仍可能认出是谁（如“孙**、满天星、10 月 29 日”），引出“去标识化不等于匿名化”。
