## 教学说明

**学习目标**

1. 能用“教授与小学生”的比喻说明 CPU 和 GPU 的区别（理解）；
2. 能解释为什么任务量很小时 GPU 不一定更快（理解）。

**画面与操作**

- 上方滑块调计算量（100 到 100 万道题，按对数刻度变化），三个快捷按钮可直接选“很少、中等、很多”；
- 下方两条跑道：CPU 的 4 个大方块、GPU 的小方块（画了 400 个代表 1000 个）在计算时变成蓝色；GPU 跑道开头的橙色段表示把数据搬上显卡；
- 比赛结束后显示谁赢了、快了多少倍。

**数据来源**：示意模型，不是实测。CPU 用时 = 题数 ÷ (4 × 10)；GPU 用时 = 50 + 题数 ÷ 1000（单位都是“毫秒”）。两者在约 2000 道题时打平。真实的差距与硬件和任务有关，可以用实验 1-2 在 CPU 和 GPU 环境下实测。

**课堂用法建议**

1. 先让学生猜：100 道题时谁快？100 万道题时谁快？再用两个快捷按钮验证；
2. 让学生找出大约多少道题时两者打平，并解释为什么打平点和“搬数据 50 毫秒”有关。
