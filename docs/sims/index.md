# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [CPU 与 GPU 谁算得快](cpu-gpu-race/index.md) | 用“4 个大核心对 1000 个小核心”的比赛，说明为什么训练模型要用 GPU，以及任务少时 GPU 不占优势 |
| 第 2 章 | [模型是怎样“看”图的](model-top5/index.md) | 换一张照片，看现成的图像分类模型给出的前 5 个答案和“把握”，理解模型只认识它学过的类别 |
| 第 3 章 | [数据增强预览](augment-preview/index.md) | 调节翻转、旋转、放大、亮度的幅度，看同一张花卉照片随机变出的 7 种样子，理解增强要“像真的” |
| 第 3 章 | [图片变数字](image-to-numbers/index.md) | 点一点照片，看每个像素的红、绿、蓝三个数字，拖动分辨率体会图片的形状（高、宽、通道） |
| 第 4 章 | [搭积木：网络结构表](layer-blocks/index.md) | 像搭积木一样增减卷积层、池化层、全连接层，实时算出每层输出形状和参数量，理解网络结构表 |
| 第 5 章 | [学习率大小的影响](learning-rate/index.md) | 用“蒙眼下山”演示梯度下降，拖动学习率，看步子太小、合适、偏大、太大时分别怎样走向损失最低点 |
| 第 5 章 | [训练五步走](train-five-steps/index.md) | 一步步演示 fit 每一批做的五件事：前向计算、计算损失、清空梯度、反向传播、更新参数，并看损失一批批下降 |
| 第 6 章 | [训练曲线诊断器](curve-doctor/index.md) | 看四组真实训练曲线，判断是欠拟合、过拟合、学习率太大还是比较健康，并给出对应的改进办法 |
| 第 7 章 | [冻结几层好](freeze-layers/index.md) | 在 MobileNetV2 的 154 层中选择解冻最后几层，看可训练参数和验证准确率的真实变化，理解迁移学习中的冻结与微调 |
| 第 8 章 | [置信度门槛](confidence-threshold/index.md) | 拖动置信度门槛，看目标检测的框和计数怎样变化，理解漏检与误检的取舍，以及检测模型只认识训练过的类别 |
| 第 9 章 | [文字变数字](text-to-numbers/index.md) | 输入一句评论，看它怎样逐字切分、查词表编号、填充或截断成固定长度的一串数字，理解词表外的字和截断的影响 |
