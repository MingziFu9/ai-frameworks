## 教学说明

**学习目标**

1. 能说出……（理解）；
2. 能用动画验证……（应用）。

**画面与操作**

- 说明画面上每个区域是什么、每个按钮做什么。

**数据来源**：写明动画里的数字从哪里来。和书中实验输出对应的，要写明“与实验 X-Y 的输出一致”，并逐个核对过。

**课堂用法建议**

1. 给出一两个课堂上可以让学生动手试的小任务。
