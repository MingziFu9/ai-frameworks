## 教学说明

**学习目标**

1. 能说出文字变数字的三步：切分、编号、填充（记忆）；
2. 能解释词表外的字（&lt;unk&gt;）和截断会让模型丢失信息（理解）。

**画面与操作**

- 在输入框里输入任意一句话，或点“试试”里的例句；
- 拖动“固定长度”，看后面补 0 或超出部分被截掉；
- 红色的字表示词表里没有，编号都变成 1。

**数据来源**：词表由实验 9-2 的 1200 条训练评论（编者生成）统计得到，和国产版代码的编号方式完全相同；通用版 `TextVectorization` 的编号顺序基本一致，标点处理略有不同。

**课堂用法建议**

1. 输入“这家的麻辣烫绝绝子”，大部分字都是红色，讨论：模型会怎么判断这句话？（提示：训练数据里没见过的说法，模型几乎是瞎猜）
2. 输入长评论，把长度拖到 8，讨论截断会丢掉什么（比如评论最后的“再也不点了”）。
