## 教学说明

**学习目标**

1. 能读懂网络结构表中每层的输出形状和参数量（理解）；
2. 能说出卷积层、池化层、展平层、全连接层对形状的影响（理解）；
3. 能分析参数量主要集中在哪一层，以及增减层对参数量的影响（分析）。

**画面与操作**

- 上方按钮把积木加到网络最下面，每行的 × 删掉一块；
- 表格按 Keras `model.summary()` 的格式显示输出形状和参数量，与实验 4-2、4-3 的运行结果一致；
- 搭错时（如全连接层前没展平）出错的那一行标红，并用大白话说明原因。

**数据来源**：按卷积层 3×3、不补边，池化层 2×2 的规则实时计算，“本书的花卉网络”总参数量 826,789，与实验 4-2 的实际输出一致。

**课堂用法建议**

1. 先点“本书的花卉网络”，让学生找出参数最多的一层（全连接层，约占 97%）；
2. 再点“少一组卷积”，先让学生猜参数是变多还是变少，再看结果（变多到约 185 万），讨论原因；
3. 故意把“全连接 64”放到“展平”前面，看报错提示。
