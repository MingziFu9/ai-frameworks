## 课程与学习方法 { #faq-1 }

??? question "我完全没学过编程，能学会这门课吗？"

    能。本书按零基础设计：第 1–4 章每章有一个“Python 小课堂”，只讲马上要用的语法，[附录 A](../appendix/a-python.md) 把全书用到的 Python 知识整理成了速查。每个实验都分三档，第一档“跑通”只要求按步骤运行、看懂结果；能做到第二档“改一改”就很好了。课程的底线是“能理解”，能用是加分。

??? question "通用版和国产版选哪个？两个都要学吗？"

    选一个学扎实就够了。想以后接触更多国外资料、开源项目，选通用版（Keras）；想用国产平台、参加国产框架相关的比赛或认证，选国产版（飞桨）。两版讲的道理完全相同，只是代码写法不同，学完一版再看另一版，大部分只要对照[附录 B](../appendix/b-libraries.md) 改几个函数名。详见 [1.2.3 节](../chapters/01-intro/index.md#123)。

??? question "书上标着“待实测”的实验是什么意思？"

    这些实验需要从飞桨服务器、Hugging Face 下载模型，或者调用大模型 API，编者的编写环境连接不上，所以只检查了代码写法，没有给出运行结果，而是附了一张记录表，请你运行后自己填写。完整清单见[附录 C.6](../appendix/c-environment.md#c6)。在 AI Studio 上运行国产版通常没有问题。

??? question "运行结果和书上不一样，是我做错了吗？"

    不一定。训练有随机性，不同电脑、不同框架版本算出来的数字会有小差别，准确率差几个百分点都正常。只要趋势一致（比如加了数据增强后验证准确率提高了），就说明做对了。如果差别很大（比如书上 80%，你只有 20%），再检查数据路径和代码有没有改错。

??? question "开卷考试要怎么准备？"

    开卷考的不是背定义，而是读懂代码、看懂结果、说出该怎么办。建议：把每章的“本章小结”和“常见报错对照”过一遍；把[附录 B](../appendix/b-libraries.md) 打印出来带进考场；做一遍[附录 F 模拟卷](../appendix/f-mock-exam.md)，限时 90 分钟。

## 实验环境与排错 { #faq-2 }

??? question "没有显卡能做实验吗？"

    能。书上所有标了运行结果的实验，都是编者在一台没有显卡的电脑上用 CPU 跑出来的，随书数据都很小，最慢的训练也只要几分钟。需要显卡的内容由老师在课堂上用学校的服务器演示。详见[附录 C.1](../appendix/c-environment.md#c1)。

??? question "云端 Notebook 和装在自己电脑上，哪个好？"

    初学推荐云端：打开网页就能用，框架已经装好，不会遇到安装问题。缺点是长时间不用会自动关闭，文件要及时保存。想离线做实验或者以后长期用，再按[实验 1-3](../chapters/01-intro/index.md#1-3) 和[附录 C.3](../appendix/c-environment.md#c3) 在自己电脑上安装。

??? question "报错了，一大片红字看不懂怎么办？"

    先只看**最后一行**，它说明了错误的类型和原因（[1.5.4 节](../chapters/01-intro/index.md#154)）。常见的几种：`ModuleNotFoundError` 是没装这个库，用 `pip install` 装上；`FileNotFoundError` 是文件路径写错了；`NameError` 通常是前面的单元格没运行；和 shape（形状）有关的错误，通常是图片大小或颜色通道顺序不对。每章最后都有一张“常见报错对照”表，还可以把报错复制给大模型请它解释（[1.6 节](../chapters/01-intro/index.md)）。

??? question "提示 FileNotFoundError，可文件明明在那里？"

    多半是“当前位置”不对。书中代码用的路径（如 `../../data/flowers_small`）是相对于实验文件所在的文件夹写的。请确认是在 `labs/chNN/keras`（或 `paddle`）文件夹里打开的 Notebook；也可以把路径改成完整路径。

??? question "第一次运行卡住很久不动，是死机了吗？"

    通常是在下载预训练模型或者数据。MobileNetV2 约 14 MB，语音模型几十 MB，网速慢时要等几分钟。如果一直下载失败，见[附录 C.5](../appendix/c-environment.md#c5) 中的国内镜像和网盘办法。

??? question "装了 MindSpore 以后，其他实验出错了？"

    MindSpore 2.11 要求 numpy 小于 2，安装时会把 numpy 降级，可能影响其他库。请为第 12 章的昇思实验单独建一个虚拟环境，或者直接在华为云的 ModelArts 上体验（[实验 12-3](../chapters/12-ecosystem/index.md#12-3)）。

## 模型与训练 { #faq-3 }

??? question "训练准确率很高，验证准确率却很低，怎么办？"

    这是过拟合，模型把训练照片“背”下来了，遇到新照片就不会。可以试：数据增强、加 Dropout、早停、减少网络参数，最有效的通常是改用迁移学习。第 6 章的四组对比实验专门讲了这个问题（[实验 6-2](../chapters/06-tuning/index.md#6-2)）。

??? question "损失一直不下降，或者变成了 nan？"

    最常见的原因是学习率太大，参数每次调得太猛，来回跳。把学习率缩小 10 倍再试。另外检查标签对不对、图片有没有换算到 0～1（[实验 5-3](../chapters/05-training/index.md#5-3)）。

??? question "为什么我的模型把不认识的花也说成五种之一？"

    分类模型只会在训练时学过的类别里选一个，最后的 Softmax 让 5 个概率加起来等于 1，所以它总会“硬选”一个，哪怕照片里根本不是这 5 种花。可以在网页里设一个门槛：最高概率低于某个值时显示“不确定”；更重要的是在模型卡里写清楚它只认识哪几类（[12.3 节](../chapters/12-ecosystem/index.md#123)）。

??? question "已经有现成模型了，为什么还要学自己训练？"

    现成模型不一定认识你要的类别（第 2 章的模型就不认识郁金香），也不一定适应你的照片。学会训练和迁移学习，就能用少量自己的数据改造现成模型（[第 7 章](../chapters/07-transfer/index.md)）。而且只有懂训练，才能看懂模型为什么出错、该怎么改。

??? question "大模型这么厉害，还需要训练小模型吗？"

    需要。大模型适合开放的、需要理解和生成的任务；小模型又快又便宜，可以离线运行，不用把数据传给别人。第 9 章把同一个评论分类任务分别交给自训练的小模型和大模型 API 做了对比（[9.4.4 节](../chapters/09-text-apps/index.md#944)），两者各有适用场合。

## 应用、安全与合规 { #faq-4 }

??? question "网页小工具在 Notebook 里好好的，发布后效果变差了？"

    最常见的原因是网页上的预处理和训练时不一样，比如训练时把像素换算到 0～1，网页上忘了换算。把换算写成模型里的一层（如 `Rescaling`）最保险。详见[第 11 章](../chapters/11-deploy/index.md)的排查表。

??? question "API 密钥能直接写在代码里吗？"

    不能，尤其是要上传到网上的代码。别人拿到密钥就能用你的账户调用大模型、产生费用。书中的做法是放在环境变量里，或者运行时用 `getpass` 输入（[实验 9-3](../chapters/09-text-apps/index.md#9-3)）。发布到云平台时，用平台提供的“密钥 / Secrets”设置。

??? question "做项目时能用同学的照片和录音吗？"

    可以，但要先告诉他们用来做什么并取得同意，只收集必要的，项目结束后按约定删除。人脸、声音属于个人信息，处理不当可能违反《个人信息保护法》（[12.4 节](../chapters/12-ecosystem/index.md#124)、[12.5 节](../chapters/12-ecosystem/index.md#125)）。

??? question "网上下载的数据集和模型，能拿来做商业产品吗？"

    要看许可。本书的花卉照片是 CC BY 2.0，可以用但要署名；第 10 章的语音合成模型所用的数据只允许非商业使用；YOLO11 的许可是 AGPL-3.0，商用要另外购买授权。各个数据和模型的许可汇总在[附录 C](../appendix/c-environment.md#c5)。
