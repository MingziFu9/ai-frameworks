# 6.2 看曲线诊断四种情况

## 曲线医生
!sim curve-doctor
- 正常：两条线一起变好
- **欠拟合**：两条都差 → 多学几轮、加大网络
- **过拟合**：训练越来越好，验证不跟 → 防过拟合
- 学习率太大：损失暴涨或卡在 1.61

# 6.3 早停：在最好的时候停下来

## 回调：交给 fit 的助手
=== "通用版"

    ```python
    stop = keras.callbacks.EarlyStopping(monitor="val_loss", patience=5,
                                         restore_best_weights=True)
    best = keras.callbacks.ModelCheckpoint("best.keras", save_best_only=True)
    model.fit(train_ds, validation_data=val_ds, epochs=30, callbacks=[stop, best])
    ```

=== "国产版"

    ```python
    stop = paddle.callbacks.EarlyStopping(monitor="loss", mode="min", patience=5,
                                          save_best_model=True)
    model.fit(train_ds, val_ds, epochs=30, batch_size=32,
              save_dir="checkpoint", callbacks=[stop])
    ```

::: notes
patience=5：验证损失连续 5 轮没变好就停，并退回最好的那一轮。像教练盯着模拟考成绩。
:::

# 6.4 对付过拟合的两件武器

## 数据增强和 Dropout
- **数据增强**：让模型见到更多样的照片（只用在训练集）
- **Dropout**：训练时随机让一部分神经元休息
- 还有：更多数据、迁移学习（第 7 章）

## 四组对比实验
| 实验 | 数据增强 | Dropout | 最高验证准确率 |
|---|---|---|---|
| ① | 不要 | 不要 | 58.0% |
| ② | 不要 | 要 | 61.3% |
| ③ | 要 | 不要 | **68.7%** |
| ④ | 要 | 要 | 66.7% |
::: notes
通用版实测，30 轮。数据增强提高了约 10 个百分点，效果最明显。国产版分别是 58.0、60.0、66.7、66.7，结论相同。
:::

# 6.5 超参数与调参的顺序

## 调参四步走
1. 先**跑起来**：代码不报错
2. 再**学得动**：训练损失能降下去
3. 再**防过拟合**：增强、Dropout、早停
4. 最后**换方法**：迁移学习
- 对比实验：**每次只改一个地方**

## 本章常见报错
| 现象 | 原因 | 办法 |
|---|---|---|
| 早停一开始就停 | patience 太小 | 改成 5 左右 |
| 曲线图是空的 | 没保存训练记录 | 用 `history`（或书中的 History 回调） |
| 看板打不开 | 日志路径不对 | 检查 `--logdir` |

## 前沿视窗：让机器自己调参
- 自动调参：机器替你试很多组超参数
- 代价：要训练很多次，费算力
- 懂原理，才知道该让它试什么
