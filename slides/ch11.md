# 11.1 让模型变成别人能用的东西

## 部署的几种方式
| 方式 | 例子 |
|---|---|
| 网页 | 本章的花卉识别网页 |
| 接口服务 | 小程序后台调用 |
| 手机 App | 拍照识花 |
| 设备端 | 摄像头、音箱 |
- 核心步骤都一样：加载 → 接收输入 → **和训练时一样的预处理** → 预测 → 展示

# 11.2 模型文件长什么样

## 常见格式
| 格式 | 来自 | 里面有什么 |
|---|---|---|
| `.keras` | Keras | 结构 + 参数 |
| `.pdparams` | 飞桨 | 只有参数 |
| `.pt` | PyTorch | 参数（或整个模型） |
| `.onnx` | 通用格式 | 结构 + 参数，任何框架都能用 |
- 来路不明的模型文件可能藏有恶意代码

# 11.3 用 Gradio 做一个网页

## 一个预测函数 + 一行 Interface
=== "通用版"

    ```python
    model = keras.models.load_model("flowers_transfer.keras")
    def predict(img):
        img = img.convert("RGB").resize((128, 128))
        p = model.predict(np.array(img, dtype="float32")[None], verbose=0)[0]
        return {NAMES[i]: float(p[i]) for i in range(5)}
    demo = gr.Interface(fn=predict, inputs=gr.Image(type="pil"),
                        outputs=gr.Label(num_top_classes=3), title="花卉识别助手")
    demo.launch()
    ```

=== "国产版"

    ```python
    net = paddle.vision.models.mobilenet_v2()          # 先搭出同样的网络
    net.classifier = nn.Sequential(nn.Dropout(0.2), nn.Linear(1280, 5), nn.Softmax())
    paddle.Model(net).load("flowers_transfer"); net.eval()
    def predict(img):
        p = net(tf(img.convert("RGB"))[None])[0].numpy()   # tf：和训练时一样的预处理
        return {NAMES[i]: float(p[i]) for i in range(5)}
    demo = gr.Interface(fn=predict, inputs=gr.Image(type="pil"),
                        outputs=gr.Label(num_top_classes=3), title="花卉识别助手")
    demo.launch()
    ```

## 生成一个链接
- 临时分享：`demo.launch(share=True)`，链接几天后失效

# 11.5 让模型更小更快

## ONNX：模型界的 PDF
| | 原框架预测一张 | ONNX Runtime 预测一张 |
|---|---|---|
| 通用版 | 64.5 毫秒 | 1.2 毫秒 |
| 国产版 | 22.3 毫秒 | 0.9 毫秒 |
- 导出后不再需要原框架，预测结果完全相同

## 量化：32 位压成 8 位
!sim model-compress
- 实测：8.9 MB → **2.7 MB**，准确率 82.67% 不变
- 在普通 CPU 上不一定变快（2.0 毫秒）
- 能不能变快取决于硬件

## 导出 ONNX
=== "通用版"

    ```python
    model.predict(x)                                  # 先运行一次
    model.export("flowers.onnx", format="onnx")
    ```

=== "国产版"

    ```python
    spec = paddle.static.InputSpec([None, 3, 128, 128], "float32", "x")
    paddle.onnx.export(net, "flowers", input_spec=[spec], opset_version=13)
    ```

# 11.6 其他部署方式

## 接口服务、手机和设备
- 接口服务：FastAPI 等，给小程序调用
- 手机：TensorFlow Lite、Paddle Lite
- 设备端：国产芯片 + 推理引擎
- 本课只做了解

## 本章常见报错
| 现象 | 原因 | 办法 |
|---|---|---|
| 网页结果总是同一种花 | 预处理和训练时不一样，或忘了 `net.eval()` | 对照训练代码 |
| `has never called` | Keras 模型还没运行过 | 导出前先 predict 一次 |
| 云平台启动失败 | requirements.txt 少写了库 | 补上库名重新部署 |

## 前沿视窗：在自己电脑上运行大模型
