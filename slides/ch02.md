# 2.1 模型、预训练模型与推理

## 三个概念
- **模型** = 结构 + **模型参数**（学到的本领）
- **预训练模型**：别人用大量数据训练好、公开出来的模型
- **推理**：让训练好的模型回答新问题
- 推理不需要标签，参数不变，计算量小

# 2.2 五行代码识别一张照片

## 三步：请出模型 → 整理照片 → 交给模型
=== "通用版"

    ```python
    model = mobilenet_v2.MobileNetV2(weights="imagenet")
    img = keras.utils.load_img(PHOTO, target_size=(224, 224))
    x = mobilenet_v2.preprocess_input(np.expand_dims(keras.utils.img_to_array(img), 0))
    pred = model.predict(x)
    print(mobilenet_v2.decode_predictions(pred, top=5))
    ```

=== "国产版"

    ```python
    from paddlex import create_model
    model = create_model(model_name="PP-LCNet_x1_0")
    for res in model.predict(PHOTO, topk=5):      # 读图、缩放都自动完成
        for name, score in zip(res["label_names"], res["scores"]):
            print(name, f"{score:.1%}")
    ```

::: notes
通用版用 Keras 自带的 MobileNetV2，国产版用 PaddleX 的 PP-LCNet。两个模型都是在 ImageNet 1000 类上训练的。
:::

## 读懂输出：置信度与 Top-5
!sim model-top5
- 模型给每一类一个**置信度**，加起来等于 1
- 通常看把握最大的 5 个：**Top-5**
- 第一名把握很低 → 模型拿不准
::: notes
动画里可以换照片，观察第一名的把握什么时候高、什么时候低。
:::

## 模型为什么会认错
- 要认的东西**不在它学过的类别里**（不认识郁金香）
- 照片里有更显眼的别的东西
- 照片和训练数据差别大（光线、角度）
- 结论：挑模型先看**能认哪些类别**

# 2.3 现成模型还能做什么

## 一行代码体验文字识别
=== "通用版"

    ```python
    from rapidocr_onnxruntime import RapidOCR
    result, _ = RapidOCR()("flower_shop_notice.png")
    for box, text, score in result:          # 位置、内容、把握
        print(text, f"{score:.0%}")
    ```

=== "国产版"

    ```python
    from paddleocr import PaddleOCR
    ocr = PaddleOCR(use_doc_orientation_classify=False,
                    use_doc_unwarping=False, use_textline_orientation=False)
    for res in ocr.predict("flower_shop_notice.png"):
        for text, score in zip(res["rec_texts"], res["rec_scores"]):
            print(text, f"{score:.0%}")
    ```

## 挑选现成模型看四件事
- 能做什么任务
- 认识哪些类别
- 大小和速度
- **使用许可**：能不能商用？要不要署名？
