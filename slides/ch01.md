# 1.1 示例小节

## 算一算：准确率

- 准确率 = 判对的样本数 ÷ 样本总数
- 3 个样本判对 2 个
- 准确率 = 2 ÷ 3 ≈ **66.7%**

::: notes
先让学生自己算，再公布答案。
:::

## 一段代码

- 用 pandas 计算准确率

```python
import pandas as pd

df = pd.DataFrame({"y_true": [1, 0, 1], "y_pred": [1, 0, 0]})
acc = (df.y_true == df.y_pred).mean()
print(f"准确率：{acc:.1%}")
```
