# 1.1 人工智能应用是怎样做出来的

## 从数据到应用的四个步骤
!mermaid 1
- **准备数据**：几百张标好名字的花卉照片
- **选择模型**：现成的，或自己搭
- **训练模型**：反复对答案、改错
- **应用上线**：用模型回答新问题，叫**推理**

## 开发框架：做 AI 的工具箱
- 像厨房电器：不用自己造锅，专心做菜
- 替你做：数字计算、自动改错、调用 GPU
- 提供：现成的“积木”（层）和现成模型
- 一句话：**框架让几行代码就能训练模型**

# 1.2 主流开发框架一览

## 通用框架和国产框架
| 类别 | 框架 | 特点 |

# 1.3 CPU、GPU 与云算力

## CPU 与 GPU 谁算得快
!sim cpu-gpu-race
- CPU：几个“大学教授”，什么题都会做
- GPU：几千个“小学生”，同时做简单加法
- 训练模型 = 海量的乘法和加法 → GPU 快
::: notes
拖动任务量，任务很少时 CPU 反而快（GPU 启动要时间），任务一多 GPU 优势明显。
:::

## 云算力：租一块显卡
- 显卡少则几千、多则几十万元，学习时不必买
- 魔搭社区：免费 CPU Notebook，适合通用版
- 飞桨 AI Studio：每天有免费 GPU 时长，适合国产版
- 本书**必做实验用 CPU 就能完成**

## 看懂报错：只看最后一行
| 最后一行 | 意思 | 怎么办 |
|---|---|---|
| `NameError: name 'x' is not defined` | 用了没定义的名字 | 先运行前面的单元格 |
| `ModuleNotFoundError` | 没装这个库 | `!pip install 库名` |
| `SyntaxError` | 写法不对 | 检查括号、引号、中文标点 |

# 1.6 前沿视窗

## 让大模型帮你写代码、解释代码
- 把报错复制给大模型，请它用大白话解释
- 让它给代码逐行加注释
- 注意：它也会**编造**不存在的函数
- 原则：**看得懂、跑得通、自己核对**再用
