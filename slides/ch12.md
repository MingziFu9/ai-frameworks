# 12.1 国产 AI 生态

## 从芯片到应用
| 层次 | 国际常用 | 国产代表 |
|---|---|---|
| 芯片 | 英伟达 GPU | 华为**昇腾** |
| 框架 | TensorFlow / Keras、PyTorch | 飞桨、昇思 |
| 模型和工具 | Hugging Face | PaddleOCR、PaddleX、魔搭社区 |

- 关键行业、数据不能出境
- 中文场景：中文模型和资料更多

- 不同框架思路相通，换起来很快

# 12.4 数据安全与隐私

## 个人信息与敏感个人信息
- **个人信息**：能识别出具体的人（姓名、电话、地址……）
- **敏感个人信息**：泄露危害大，要**单独同意**
  - 身份证号、银行卡号、人脸、声纹、行踪……
- 收集前告知、只收必要的、用完删除

## 脱敏：把关键部分遮住
!sim desensitize
- 有固定格式的：用**正则表达式**找
- 人名：要靠模型，而且会出错
- 自动脱敏会漏也会误伤，**必须人工检查**

## 正则表达式 + 部分遮盖
```python
RULES = [("身份证号", r"\d{17}[\dXx]", 6, 4),
         ("手机号", r"1[3-9]\d-?\d{4}-?\d{4}", 3, 4)]
for name, pattern, head, tail in RULES:
    text = re.sub(pattern, lambda m: mask(m.group(), head, tail), text)
```
- 13812345678 → 138\*\*\*\*5678
- jieba 曾把“满天星”“红玫瑰”当人名 → 加进白名单

## 项目要求与评分
- 能用：Gradio 网页，最好发布成链接（20 分）
- 有数据：数量达标、来源合法、处理隐私（20 分）
- 有训练和记录：至少 3 次改进（20 分）
- 有评估：准确率 + 至少 3 个错例分析（20 分）
- 有报告：需求、数据、结果、局限、模型卡（选题 10 + 报告展示 10 分）

## 本章常见报错
| 报错 | 原因 | 办法 |
|---|---|---|
| `Unable to avoid copy` | 昇思不支持 NumPy 2 | `pip install "numpy<2"` |
| 正则什么都没找到 | 规则太严或有全角数字、空格 | 先 `re.findall` 测试 |
| 不该遮的词被遮住 | 分词把普通词当人名 | 加进白名单 `KEEP` |
