# 10.1 声音怎样变成数字

## 采样率与波形
!sim hear-sound
- 每秒记下几千个数：**采样率**
  - 8000 Hz：电话、本章指令数据
  - 16000 Hz：大多数语音识别模型
- 按时间画出来就是**波形**

## 一个词的波形
![yes 的波形](images/wave_yes.png)
- 1 秒 8000 Hz → 8000 个数
- 声音大的地方波动大

## 声谱图：把声音画成图片
![yes 和 no 的声谱图](images/spec_yes_no.png)
- 横轴时间、纵轴频率、颜色表示强弱
- 不同的词“长得”不一样
- **声谱图就是一张单色图片**

# 10.2 用现成模型识别和合成语音

## 语音识别与语音合成
- **语音识别**：声音 → 文字
- **语音合成**：文字 → 声音
- 工具：sherpa-onnx，离线运行
- 通用版 Whisper tiny，国产版 Paraformer

## 实测对比：店名最容易认错
| 原文 | Whisper tiny | Paraformer |
|---|---|---|
| 您好，您的外卖已经送到门口了。 | 您好您的外賣已經送到門口了 | 您好您的外卖已经送到门口了 |
| 今天的玫瑰八折，欢迎选购。 | 今天的美閣八者會影選購 | 今天的玫瑰八折欢迎选购 |
| 花语小铺今天玫瑰八折…… | 巴魚小鋪今天玫瑰巴折…… | 花鱼小铺今天玫瑰八折会迎选购 |
::: notes
合成的声音再交给识别模型。Whisper 输出繁体字，中文专用的 Paraformer 明显更准；店名、人名两个都容易错。
:::

# 10.3 训练语音指令识别器

## 第一块积木：声音变声谱图
=== "通用版"

    ```python
    model = keras.Sequential([
        keras.Input(shape=(8000, 1)), layers.Reshape((8000,)),
        layers.MelSpectrogram(sampling_rate=8000, fft_length=256,
                              sequence_stride=128, num_mel_bins=40),
        layers.Reshape((40, 63, 1)),          # 当成一张单色图片
        layers.BatchNormalization(),
        layers.Conv2D(16, 3, activation="relu"), layers.MaxPooling2D(),
        layers.Conv2D(32, 3, activation="relu"), layers.MaxPooling2D(),
        layers.Flatten(), layers.Dropout(0.3),
        layers.Dense(64, activation="relu"), layers.Dense(8, activation="softmax")])
    ```

=== "国产版"

    ```python
    net = nn.Sequential(
        LogMelSpectrogram(sr=8000, n_fft=256, hop_length=128, n_mels=40),
        nn.Unflatten(1, [1, 40]),             # 加一个通道，当成单色图片
        nn.BatchNorm2D(1),
        nn.Conv2D(1, 16, 3), nn.ReLU(), nn.MaxPool2D(2),
        nn.Conv2D(16, 32, 3), nn.ReLU(), nn.MaxPool2D(2),
        nn.Flatten(), nn.Dropout(0.3),
        nn.Linear(32 * 8 * 14, 64), nn.ReLU(), nn.Linear(64, 8), nn.Softmax())
    ```

## 结果：又过拟合了
| | 训练准确率 | 验证准确率 |
|---|---|---|
| 通用版 | 96.7% | 66.9% |
| 国产版 | 99.4% | 55.0% |
- 8 个词，每个只有 100 条录音
- 原因和办法都和花卉识别一样：多录、增强、Dropout、早停
::: notes
后面就是第 4 章的卷积网络，只是输入换成了声谱图。这正是“学会一种方法用到多种数据上”。
:::

# 10.4 声音的权益

## 录音要授权、合成要标识
- 声音能认出一个人，受法律保护
- 录同学的声音，要先说明用途、取得同意
- 合成的语音对外发布，要**标识**是 AI 生成
- 用模型和数据先看**许可**：本章合成模型的数据只允许非商业使用

## 本章常见报错
| 报错 | 原因 | 办法 |
|---|---|---|
| `URLError`、`timed out` | 连不上 GitHub | 换平台或请老师放共享目录 |
| `Cannot reshape array ... (40,63,1)` | 声谱图大小和 Reshape 不一致 | 改回原采样率和长度 |
| 识别结果全是繁体 | Whisper 的特点 | 用 opencc 转简体，或改用 Paraformer |

## 前沿视窗：能实时对话的语音大模型
- 直接听、直接说，不再先转文字
- 能听出语气，能被打断
- 声音克隆更容易了，防骗更重要
