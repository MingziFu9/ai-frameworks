# 7.1 迁移学习

## 把学过的本领用到新任务上
- 预训练模型在 ImageNet 上学会了看边缘、颜色、纹理
- 这些**特征**是通用的，换个任务也有用
- 只需要教它：“这些特征组合起来是哪种花”

## 什么时候用
| 情况 | 推荐做法 |
|---|---|
| 现成模型已经认识 | 直接用现成模型 |
| 不认识，自己数据**不多** | **迁移学习** |
| 数据非常多、任务差别很大 | 从零训练 |

# 7.2 三步做迁移学习

## 请出 → 冻结 → 接新输出层
!sim freeze-layers
1. 请出预训练模型，去掉原来 1000 类的输出层
2. **冻结**：训练时不改它的参数
3. 接上自己的输出层：5 种花
- 要学的参数从 83 万降到 **6,405** 个

## 代码
=== "通用版"

    ```python
    base = keras.applications.MobileNetV2(input_shape=(128, 128, 3),
                                          include_top=False, weights="imagenet")
    base.trainable = False                          # 冻结
    model = keras.Sequential([
        keras.Input(shape=(128, 128, 3)),
        layers.Rescaling(1 / 127.5, offset=-1),     # 换算到 -1～1
        base, layers.GlobalAveragePooling2D(), layers.Dropout(0.2),
        layers.Dense(5, activation="softmax")])
    ```

=== "国产版"

    ```python
    net = paddle.vision.models.mobilenet_v2(pretrained=True)
    for p in net.parameters():
        p.stop_gradient = True                      # 冻结
    net.classifier = nn.Sequential(nn.Dropout(0.2), nn.Linear(1280, 5), nn.Softmax())
    model = paddle.Model(net)
    model.prepare(paddle.optimizer.Adam(learning_rate=0.001,
                  parameters=net.classifier.parameters()),   # 只训练新层
                  nn.CrossEntropyLoss(use_softmax=False), paddle.metric.Accuracy())
    ```

::: notes
国产版预训练参数要从飞桨服务器下载，编者环境无法连接，书中标“待实测”，请在 AI Studio 上运行。像素换算一定要和预训练模型的要求一致。
:::

# 7.3 效果：从五成多到八成多

## 同样 600 张、同样 10 轮
| | 要学的参数 | 第 1 轮验证 | 第 10 轮验证 |
|---|---|---|---|
| 从零训练（第 5 章） | 826,789 | 39.3% | 54.7% |
| 迁移学习（本章） | 6,405 | **64.0%** | **82.7%** |
- 10 张测试照片认对 9 张

# 7.4 微调：解冻后面几层

## 先训练输出层，再小步微调
- 解冻预训练模型**最后几层**
- 学习率调到很小（如 0.00001）
- 数据越少，解冻越少

| 解冻最后几层 | 可训练参数 | 验证准确率 |
|---|---|---|
| 0（不微调） | 6,405 | 82.7% |
| 30 | 1,532,805 | **86.0%** |
| 154（全部） | 2,230,277 | 84.0% |

# 7.5 错误分析：混淆矩阵

## 哪两类最容易混
![混淆矩阵](images/confusion.png)
- 行：真实类别；列：预测类别
- 对角线：认对的
- 对角线以外：认错的，看是谁错成了谁

## 看看认错的照片
![认错的照片](images/wrong.png)
- 花太小、背景太乱、光线暗
- 一张图里有好几种花
- 有的照片标签本身就可疑
::: notes
错误分析要分清：是模型的问题（学得不够）还是数据的问题（照片质量、标签错误），对症改进。
:::

# 7.6 低代码训练

## 不写代码也能迁移学习
- Teachable Machine：网页上拖照片就能训练
- 飞桨 PaddleX：配置文件 + 一条命令
- 它们把“请出、冻结、接新层”包装好了
- **懂原理才能用好**：知道什么时候效果不好、为什么

## 本章常见报错
| 现象 | 原因 | 办法 |
|---|---|---|
| 准确率和瞎猜一样 | 像素换算和预训练要求不一致 | 检查 Rescaling / Normalize |
| 微调后变差 | 学习率太大，破坏了学到的特征 | 学习率再小 10 倍 |
| 下载权重失败 | 网络连不上 | 换平台或用国内镜像（附录 C） |

## 前沿视窗：预训练 + 微调
- 大模型时代的标准做法
- 基础模型由大公司训练
- 各行各业用自己的数据微调
