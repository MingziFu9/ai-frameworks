# 8.2 目标检测

## 几行代码做检测
=== "通用版"

    ```python
    from ultralytics import YOLO
    model = YOLO("yolo11n.pt")
    r = model.predict(PHOTO, conf=0.4)[0]     # 把握低于 40% 的不要
    for box, cls, score in zip(r.boxes.xyxy, r.boxes.cls, r.boxes.conf):
        print(model.names[int(cls)], f"{score:.0%}", box)
    ```

=== "国产版"

    ```python
    from paddlex import create_model
    model = create_model("PP-YOLOE_plus-S")
    r = next(model.predict(PHOTO, threshold=0.4))
    for b in r["boxes"]:
        print(b["label"], f"{b['score']:.0%}", b["coordinate"])
    ```

## 置信度阈值
!sim confidence-threshold
| 门槛 | 0.2 | 0.4 | 0.6 |
|---|---|---|---|
| 数出来的人数 | 13 | 10 | 6 |
- 门槛低：多报，门槛高：少报
- 按用途定：安防宁可多报，计数要准

# 8.5 能做和不能做

## 人脸、隐私与授权
| 做法 | 能不能 |
|---|---|
| 数花田里有几个人，不认是谁 | 一般可以，最好张贴告示 |
| 存下游客照片，认出是谁 | 不可以随意做，需单独同意 |
| 拍别人身份证做 OCR 上传网络 | 不可以 |
- 能只数数就不认人，能不采集就不采集

## 本章常见报错
| 现象 | 原因 | 办法 |
|---|---|---|
| 一个框都没有 | 门槛太高或不在 80 类里 | 门槛调到 0.2 |
| `could not convert string to float` | OCR 把 0 认成了 O | 人工检查这一格 |
| 表格少了一行 | 某格没认出来 | 打印出来人工补 |
