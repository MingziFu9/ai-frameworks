# 9.4 调用大模型 API

## API 与提示词
- **大语言模型**通过 **API** 调用：发一段文字，收一段回答
- **提示词**说清三件事：角色、任务、输出格式
- API Key 是“钥匙”：**不能写进代码、不能上传**

## 两版写法几乎一样
=== "通用版"

    ```python
    api_key = os.environ.get("DEEPSEEK_API_KEY") or getpass("请粘贴 API Key：")
    client = OpenAI(api_key=api_key, base_url="https://api.deepseek.com")
    r = client.chat.completions.create(model="deepseek-chat", temperature=0,
        messages=[{"role": "user", "content": PROMPT.format(text)}])
    print(r.choices[0].message.content)
    ```

=== "国产版"

    ```python
    api_key = os.environ.get("QIANFAN_API_KEY") or getpass("请粘贴 API Key：")
    client = OpenAI(api_key=api_key, base_url="https://qianfan.baidubce.com/v2")
    r = client.chat.completions.create(model="ernie-4.5-turbo-32k", temperature=0,
        messages=[{"role": "user", "content": PROMPT.format(text)}])
    print(r.choices[0].message.content)
    ```

## 小模型还是大模型
| | 自己训练的小模型 | 大模型 API |
|---|---|---|
| 要标注数据 | 要 | 不要 |
| 速度、成本 | 快、几乎免费 | 慢一些、按量付费 |
| 数据去向 | 不出本机 | 发给平台 |
| 理解力 | 只懂学过的说法 | 强 |
- 常见做法：**大小搭配**

## 本章常见报错
| 报错 | 原因 | 办法 |
|---|---|---|
| `ConnectionError`、`timed out` | 连不上模型平台 | 设置镜像 `HF_ENDPOINT`，或换平台 |
| `KeyError: 'DEEPSEEK_API_KEY'` | 环境变量里没有 Key | 设置环境变量，或用 `getpass` 粘贴 |
| `AuthenticationError`、`401` | Key 错了、过期或多了空格 | 重新复制 Key |
| `RateLimitError`、`429` | 调用太快或余额不足 | 加 `time.sleep(1)`，查余额 |

## 前沿视窗：大模型和小模型怎么分工
- 大模型生成训练数据、标注疑难样本
- 小模型上线跑日常的大量请求
- 拿不准的再交给大模型或人工
