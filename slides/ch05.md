# 5.1 训练前的三项设置

## 判卷标准、改错方法、成绩单
- **损失函数**：判卷标准，答案和标准答案差多少（分类用交叉熵）
- **优化器**：改错方法（常用 Adam）
- **评价指标**：成绩单（常用准确率）
- 五选一瞎猜时，损失约为 **1.61**

## 用代码写出三项设置
=== "通用版"

    ```python
    model.compile(
        loss="sparse_categorical_crossentropy",
        optimizer=keras.optimizers.Adam(learning_rate=0.001),
        metrics=["accuracy"])
    ```

=== "国产版"

    ```python
    model = paddle.Model(net)               # 套上高层 API 的外壳
    model.prepare(
        optimizer=paddle.optimizer.Adam(learning_rate=0.001,
                                        parameters=model.parameters()),
        loss=nn.CrossEntropyLoss(use_softmax=False),
        metrics=paddle.metric.Accuracy())
    ```

::: notes
国产版末层已经有 Softmax，所以损失里写 use_softmax=False，避免做两次。优化器要交 parameters，漏写会报错。
:::

# 5.2 开始训练：fit

## 一行代码开始上课
=== "通用版"

    ```python
    history = model.fit(train_ds, validation_data=val_ds, epochs=10)
    ```

=== "国产版"

    ```python
    model.fit(train_ds, val_ds, epochs=10, batch_size=32, shuffle=True,
              verbose=1, log_freq=100)
    ```

## 读懂训练日志
```text
Epoch 1/10
19/19 - accuracy: 0.2850 - loss: 1.5286 - val_accuracy: 0.3933 - val_loss: 1.3384
Epoch 10/10
19/19 - accuracy: 0.8683 - loss: 0.3703 - val_accuracy: 0.5467 - val_loss: 1.6601
```
- 19/19：600 张 ÷ 每批 32 张 ≈ 19 批
- 训练准确率 86.8%，验证准确率只有 54.7%
::: notes
这是通用版的实测日志。两个准确率差这么多，说明模型在“背答案”，这是第 6 章要解决的问题。
:::

# 5.3 打开盒子：fit 背后的五个步骤

## 一批数据的五步
!sim train-five-steps
1. 前向计算：模型做题
2. 计算损失：对答案
3. 清空梯度：擦掉上次的草稿
4. **反向传播**：算出每个参数该往哪边改（**梯度**）
5. 更新参数：按学习率改一点

## 训练循环：两层 for 循环
- 外层：一轮一轮（**轮次**）
- 内层：一批一批
- 每一批都走一遍五个步骤
- `fit` 就是把这两层循环替你写好了
::: notes
实验 5-2 给出了一段手写训练循环（通用版用 PyTorch 对照，国产版用飞桨），要求读懂每一行对应哪一步，不要求自己会写。
:::

# 5.4 轮次、批大小和学习率

## 学习率大小的影响
!sim learning-rate
- 太大：来回跳，甚至“炸掉”
- 太小：学得太慢
- 0.001 是好起点

## 实测：三种学习率
| 学习率 | 训练准确率 | 验证准确率 | 表现 |
|---|---|---|---|
| 0.1 | 19.3% | 18.0% | 太大，停在瞎猜水平 |
| 0.001 | 86.8% | 54.7% | 合适 |
| 0.00001 | 36.2% | 35.3% | 太小，10 轮几乎没学 |
::: notes
表中是通用版数字。国产版分别是 22.3/10.7、90.2/50.7、55.8/50.7，趋势相同。
:::

# 5.5 保存模型、加载并预测

## 保存和加载
=== "通用版"

    ```python
    model.save("flowers_cnn.keras")                       # 结构 + 参数，一个文件
    model = keras.models.load_model("flowers_cnn.keras")
    prob = model.predict(x)[0]
    ```

=== "国产版"

    ```python
    model.save("flowers_cnn")          # 得到 flowers_cnn.pdparams 等文件（只有参数）
    # 加载前先搭好同样的网络 net，再：
    model = paddle.Model(net); model.load("flowers_cnn")
    prob = net(x)[0].numpy()
    ```

## 本章常见报错
| 报错 | 原因 | 办法 |
|---|---|---|
| `You must call compile()` | 跳过了三项设置 | 按顺序运行 |
| 损失变成 `nan` | 学习率太大 | 缩小 10 倍 |
| 损失停在 1.61 | 没学到东西 | 检查学习率和标签 |
