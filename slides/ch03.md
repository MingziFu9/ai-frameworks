# 3.1 图片在框架里是一张“数字表”

## 像素与颜色通道
!sim image-to-numbers
- 照片由一个个小格子（像素）拼成
- 每个像素记红、绿、蓝三个数，0～255
- 彩色图片 = **高 × 宽 × 3 个通道**
::: notes
在动画里把鼠标放到一个像素上，看它的三个数。纯红是 (255, 0, 0)。
:::

## 训练前的两件事
- **统一大小**：都缩到 128 × 128
- **归一化**：0～255 除以 255，变成 0～1
- 数字小一点，模型学得更稳

# 3.2 张量：装数据的“多层盒子”

## 从一个数到一批照片
| 数据 | 形状 |
|---|---|
| 一个数 | `()` |
| 一行数 | `(4,)` |
| 一张彩色照片 | `(128, 128, 3)` |
| 一批 32 张照片 | `(32, 128, 128, 3)` |

## 两版通道位置不一样
- 通用版（Keras）：通道在**最后** `(32, 128, 128, 3)`
- 国产版（飞桨）：通道在**最前** `[32, 3, 128, 128]`
- 形状对不上是最常见的报错之一
- 飞桨画图前要 `transpose([1, 2, 0])` 把通道挪到最后

# 3.3 数据集：把几百张照片整理好

## 一类一个文件夹
- `flowers_small/daisy/`、`roses/`、`tulips/`……
- 文件夹名就是**标签**，按字母顺序编号 0～4
- 本书：5 类，每类 150 张，共 750 张
- **训练集**（练习题）600 张，**验证集**（模拟考）150 张

## 几行代码读入整个数据集
=== "通用版"

    ```python
    train_ds, val_ds = keras.utils.image_dataset_from_directory(
        DATA, validation_split=0.2, subset="both", seed=42,
        image_size=(128, 128), batch_size=32)
    print(train_ds.class_names)
    ```

=== "国产版"

    ```python
    tf = T.Compose([T.Resize((128, 128)), T.ToTensor()])
    full = DatasetFolder(DATA, transform=tf)
    train_ds, val_ds = paddle.io.random_split(full, [600, 150])
    loader = paddle.io.DataLoader(train_ds, batch_size=32, shuffle=True)
    ```

::: notes
seed 固定后，每次分出来的训练集和验证集都一样，结果可以重现。
:::

# 3.4 数据增强

## 一张照片当几张用
!sim augment-preview
- 随机翻转、旋转、缩放
- 让模型见到更多样的照片，不死记
- 只用在**训练集**，变化要“像真的”
::: notes
上下翻转的花在现实中很少见，用了反而有害。增强要符合真实拍照会出现的变化。
:::

## 几块“变换积木”
=== "通用版"

    ```python
    augment = keras.Sequential([
        layers.RandomFlip("horizontal"),   # 左右翻转
        layers.RandomRotation(0.1),        # 转 ±0.1 圈 = ±36 度
        layers.RandomZoom(0.2),            # 放大缩小 20%
    ])
    ```

=== "国产版"

    ```python
    tf = T.Compose([
        T.RandomHorizontalFlip(),                     # 左右翻转
        T.RandomRotation(36),                         # 转 ±36 度
        T.RandomResizedCrop(128, scale=(0.6, 1.0)),   # 随机裁一块再放大
        T.ToTensor()])
    ```

# 3.5 文字和声音怎样变成数字

## 进了框架，都是张量
- **文字**：查字典，每个字换成一个编号（第 9 章）
- **声音**：每秒记几千个数，一段录音是一长串数（第 10 章）
- 图片、文字、声音 → 都是张量

## 索引和字典
```python
names = ["daisy", "dandelion", "roses"]
print(names[0])          # 索引从 0 开始 → daisy
print(names[-1])         # 倒数第一个 → roses
price = {"玫瑰": 5, "郁金香": 8}
print(price["玫瑰"])     # 字典按键查值 → 5
```

## 本章常见报错
| 报错 | 原因 | 办法 |
|---|---|---|
| `IndexError: list index out of range` | 索引超出范围 | 记住从 0 数起 |
| `KeyError: '百合'` | 字典里没有这个键 | 检查拼写 |
| `No images found` / 找不到文件 | 路径不对 | 检查当前位置和路径 |
