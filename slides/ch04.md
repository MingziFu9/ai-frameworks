# 4.1 神经网络：一层一层传话的流水线

## 神经元：一个会打分的评委
!sim layer-blocks
- 输入乘上**权重**、加上**偏置**，得到分数
- 再经过**激活函数**（门槛）输出
- 权重和偏置就是要学的**参数**
::: notes
动画里拖动权重，看输出怎么变。这里只要理解“加权打分”，不需要公式推导。
:::

## 层和网络
- 很多神经元排成一**层**
- 很多层摞起来 = **神经网络**
- 输入层 → 隐藏层 → 输出层
- 隐藏层用 **ReLU**：负数变 0
- 分类输出层用 **Softmax**：分数变概率

# 4.2 第一个网络：认鸢尾花

## 4 个数 → 3 种花
=== "通用版"

    ```python
    model = keras.Sequential([
        keras.Input(shape=(4,)),               # 每朵花 4 个数
        layers.Dense(8, activation="relu"),    # 隐藏层 8 个神经元
        layers.Dense(3, activation="softmax"), # 3 种花的概率
    ])
    model.summary()
    ```

=== "国产版"

    ```python
    net = nn.Sequential(
        nn.Linear(4, 8), nn.ReLU(),     # 输入 4 个数 → 8 个神经元
        nn.Linear(8, 3), nn.Softmax())  # 3 种花的概率
    paddle.summary(net, (1, 4))
    ```

## 两版写法的差别
| | 通用版 | 国产版 |
|---|---|---|
| 全连接层 | `Dense(8)` 只写输出数 | `Linear(4, 8)` 输入输出都写 |
| 激活函数 | 写在层里 `activation="relu"` | 单独一块 `nn.ReLU()` |
| 结构表 | `model.summary()` | `paddle.summary(net, 形状)` |

# 4.3 卷积网络：用“放大镜”看图片

## 为什么要卷积
- 全连接层看图片：参数太多，也不懂“相邻”
- **卷积层**：拿 3×3 的放大镜一格一格扫，找边缘、纹理
- **池化层**：缩成一半，只留最明显的
- **展平层**：把图片拉成一长串，交给全连接层

## 搭出花卉卷积网络
=== "通用版"

    ```python
    model = keras.Sequential([
        keras.Input(shape=(128, 128, 3)), layers.Rescaling(1 / 255),
        layers.Conv2D(16, 3, activation="relu"), layers.MaxPooling2D(),
        layers.Conv2D(32, 3, activation="relu"), layers.MaxPooling2D(),
        layers.Conv2D(64, 3, activation="relu"), layers.MaxPooling2D(),
        layers.Flatten(),
        layers.Dense(64, activation="relu"),
        layers.Dense(5, activation="softmax")])
    ```

=== "国产版"

    ```python
    net = nn.Sequential(
        nn.Conv2D(3, 16, 3), nn.ReLU(), nn.MaxPool2D(2),
        nn.Conv2D(16, 32, 3), nn.ReLU(), nn.MaxPool2D(2),
        nn.Conv2D(32, 64, 3), nn.ReLU(), nn.MaxPool2D(2),
        nn.Flatten(),
        nn.Linear(64 * 14 * 14, 64), nn.ReLU(),
        nn.Linear(64, 5), nn.Softmax())
    ```

# 4.4 读懂网络结构表

## 一行一行读
| 层 | 输出形状 | 参数量 |
|---|---|---|
| 卷积 16 | 126 × 126 × 16 | 448 |
| 池化 | 63 × 63 × 16 | 0 |
| 卷积 32 → 池化 | 30 × 30 × 32 | 4,640 |
| 卷积 64 → 池化 | 14 × 14 × 64 | 18,496 |
| 展平 | 12,544 | 0 |
| 全连接 64 | 64 | 802,880 |
| 输出 5 | 5 | 325 |
::: notes
合计 826,789 个参数，97% 在第一个全连接层。3×3 卷积不补边，每次边长少 2；池化边长减半。
:::

## 参数量怎么算
- 全连接层：（输入数 + 1）× 神经元数
  - (12544 + 1) × 64 = 802,880
- 卷积层：（3 × 3 × 输入通道 + 1）× 放大镜数
  - (3 × 3 × 3 + 1) × 16 = 448
- 少一组卷积，展平后更长，参数**反而更多**
